How Data User works

  1. 1
    Describe the need

    Ask naturally and add requirements only when they matter.

  2. 2
    Route through Plaza

    Data User sends data_request to Data Consultant's data_advice Pulse.

  3. 3
    Search source memory

    Data Consultant retrieves matching endpoint and field documentation synchronized from YFinance. No provider observations are fetched and no LLM is called.

  4. 4
    Call the source directly

    Data User resolves YFinance through Consultant status, then uses data_spec or data_fetch on the Data Source.
