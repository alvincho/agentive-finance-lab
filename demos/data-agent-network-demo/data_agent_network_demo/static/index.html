Agentive Finance Lab · Demo 001 · Launch brief

See a financial data request become an inspectable agent handoff.

This standalone open-source lab reduces the original framework ideas to one workable task: a Data User delegates a security-versus-benchmark comparison to a Data Consultant, which retrieves evidence only through yfinance.

Project background

The point is not better arithmetic. The demo makes ownership, capability discovery, acceptance checks, provider failure, and one end-to-end trace visible without exposing the original FinMAS implementation.

PROJECT BACKGROUND · AGENTIVE FINANCE LAB

Make the handoff—not just the answer—visible.

This standalone open-source demo reduces two frameworks to the smallest contracts needed to expose delegation, discovery, typed handoff, acceptance, and traceability.

The agents do not improve the arithmetic. The Data User owns intent and acceptance; the Data Consultant owns yfinance retrieval and analysis; Plaza connects them by capability.

  • standalone repository
  • not FinMAS
  • yfinance only
  • no synthetic fallback
  • not investment advice
