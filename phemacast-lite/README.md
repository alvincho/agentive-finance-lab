# Phemacast Lite

Generic collaboration concepts layered on `prompits_lite`:

- `PulseSpec` with discoverable input/output fields and runtime types
- `Pulser` with contract validation around local handlers
- `PersonaProfile`
- runtime `Persona`

It contains no finance vocabulary and no Phema/Phemar/Castr implementation. It
must not import from a demo package.
