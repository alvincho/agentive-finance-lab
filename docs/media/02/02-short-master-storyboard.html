AGENTIVE FINANCE LAB · EPISODE 2

Clone.
Start.
Inspect.

One local host · three Data Agent demos

1 · CLONE + ENVIRONMENT

Start from a clean checkout.

git clone https://github.com/alvincho/agentive-finance-lab.git
cd agentive-finance-lab
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .

Python 3.11+ · no API key or model account required

2 · ONE LAUNCHER

Start the local host.

python demos/data-agent-network-demo/run.py --open

Uvicorn running on
http://127.0.0.1:8000

The launcher keeps running until Ctrl+C.

3 · VERIFY HEALTH

/health makes the first result inspectable.

{
  "status": "ok",
  "participants": 3,
  "sources": 1,
  "provider": "yfinance"
}

Local network health does not guarantee provider availability.
